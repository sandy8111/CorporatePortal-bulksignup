SIM categories: who can use them

With a UEN, only that company's account officers can choose the category. Without one, every company can. Categories that have inventory but were never allocated are also open to all companies. Saving a category again changes who can use it; deactivating hides it from everyone.

The header row is optional. Without it, put one ICCID per line and set the defaults above. New SIMs pair automatically with available numbers in the same category: SIMs in this file first, then any numbers left over go to SIMs uploaded earlier that are still waiting. Rows that fail are listed with a reason; the rest are loaded.
